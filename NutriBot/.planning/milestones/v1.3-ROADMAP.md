# Milestone v1.3: Structured Data & Claims

**Status:** ✅ SHIPPED 2025-02-18
**Phases:** 11-18
**Total Plans:** 8

## Overview

Structured data entry tied to tasks, starting with Monthly Claims tracking and trends. TaskDataField + TaskDataValue models; claim fields on Monthly Claim Submission template; data entry UI, backfill mode, claims dashboard, Today widget, CSV export, onboarding toggle. Local only, additive (no destructive schema changes), fast.

## Milestone Summary

**Key Decisions:**
- TaskDataField + TaskDataValue for flexible structured data (no schema changes to TaskInstance)
- value_text storage; parse by data_type
- enable_monthly_claims_tracking in settings (default true)

**Technical Debt Incurred:**
- Backfill: no year selector UI; unchecked bools don't clear
- Exports: claims CSV link shown even when tracking disabled
- Phases 11-18: no formal phase VERIFICATION.md files
