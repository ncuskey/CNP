## v1.2 Requirements

### Onboarding Wizard

- [x] **ONB-01**: User completes onboarding wizard (district profile, programs, deadlines, evidence defaults, paths, seed setup)
- [x] **ONB-02**: Onboarding saves to `data/settings.json` (no schema changes)
- [x] **ONB-03**: If onboarding incomplete, /today redirects to /onboarding (with skip link)
- [x] **ONB-04**: Dismissible banner on /today when onboarding incomplete
- [x] **ONB-05**: User can edit onboarding via /settings after completion

### Regulations Library

- [x] **REG-01**: User can list regulations with filters (authority, topic, review due)
- [x] **REG-02**: User can add regulation entries (metadata in `data/reg_library.json`)
- [x] **REG-03**: User can upload PDF to vault/_regulations/ per regulation
- [x] **REG-04**: User can mark regulation as reviewed (updates last_reviewed, next_review_due)
- [x] **REG-05**: "Review due" badge when next_review_due within 30 days
- [x] **REG-06**: Seed recommended regs (starter list with USDA/Idaho links, no PDFs)

### Integration

- [x] **INT-01**: Presets: "Annual Regulations Review" task template suggestion
- [x] **INT-02**: Review page: "Regulations review due soon: N" widget linking to /regulations?due=soon
